# قائمة الميزات: ما يعمل فعليًا وما لم يُنفَّذ

## ✅ ميزات تعمل فعليًا ومُختبرة

### البنية العامة
- ملف XLSX واحد بلا ماكرو/VBA (يفتح مباشرة دون تحذيرات أمنية).
- 31 ورقة عمل مترابطة، كلها باتجاه **من اليمين إلى اليسار**.
- تصميم موحد (ألوان، خطوط، عناوين، تنسيق شرطي).
- **تجميد الألواح** في كل ورقة (رؤوس ثابتة عند التمرير).
- **فلاتر تلقائية** في كل أوراق الإدخال.
- **تحقق من صحة البيانات**: 40 قاعدة تحقق، أغلبها قوائم منسدلة مرتبطة بورقة الإعدادات.
- **تنسيق شرطي** للحالات المهمة (الحالات، التأخير، انتهاء العقود والوثائق، التكرار).
- **إعداد الطباعة**: A4 أفقي، ملاءمة العرض، تكرار صف العناوين، ترقيم الصفحات.
- **حماية الأوراق**: خلايا الإدخال مفتوحة وخلايا الحساب مقفلة (كلمة المرور `hr2026`).

### لوحة التحكم
- 20 مؤشرًا: 12 للقوى العاملة و8 مالية — محسوبة بالكامل بمعادلات.
- 7 تنبيهات ذكية ملوّنة تلقائيًا.
- 4 رسوم بيانية أصلية (أعمدة، دائري، خطي، أعمدة أفقية).
- تتحدّث تلقائيًا عند تعديل البيانات.

### الموظفون
- 29 حقلًا لكل موظف.
- منع تكرار الرقم الوظيفي عبر تحقق مخصص.
- فحص اكتمال البيانات وتنبيه «⚠ بيانات ناقصة».
- حساب أيام انتهاء العقد ومدة الخدمة تلقائيًا.
- تنبيه قرب انتهاء العقد.

### الحضور
- استرجاع الاسم ويوم الأسبوع وأوقات الدوام تلقائيًا.
- حساب ساعات العمل والتأخير والانصراف المبكر والإضافي.
- دعم الدوام الليلي (تجاوز منتصف الليل) عبر `MOD`.
- عدم احتساب التأخير في الإجازات والعطلات والمأموريات.

### الإجازات
- حساب عدد الأيام والرصيد قبل/بعد تلقائيًا.
- عدم خصم الإجازة إلا عند الاعتماد.
- رصيد افتتاحي + استحقاق شهري قابل للتعديل.

### الرواتب
- استرجاع الاسم والإدارة والقسم والراتب الأساسي تلقائيًا.
- حساب الاستحقاقات والخصومات والصافي بمعادلات.
- كشف تكرار الراتب (موظف + شهر + سنة).
- ربط أقساط السلف برقم السلفة لمنع الخصم المزدوج.

### السلف والوثائق
- حساب قيمة القسط والمسدد والمتبقي.
- تنبيهات انتهاء الوثائق (90/30/7/منتهية) بتلوين متدرج.

### بقية الأوراق
- التوظيف، التدريب، تقييم الأداء (متوسط مرجّح بأوزان قابلة للتعديل)، الجزاءات والمكافآت، إنهاء الخدمة (مع تنبيه العهد)، العهد.

### التقارير
- 14 تقريرًا جاهزًا للطباعة.
- تقرير الرواتب الشهري بفلترة حسب الشهر/السنة.
- تقرير التأخير وتقرير الوثائق يعرضان الصفوف المطابقة فقط.

## ⚠ ميزات جزئية أو تحتاج خطوة يدوية

| الميزة | الحالة | التفصيل |
|---|---|---|
| شعار المؤسسة | جزئي | لا يمكن تضمين صورة برمجيًا في ملف XLSX نصي؛ أدرج الشعار يدويًا (إدراج ← صورة) في خلية الإعدادات. |
| تسعير العمل الإضافي | جزئي | تُدخل **قيمة** الإضافي كمبلغ في كشف الرواتب؛ لا يوجد تسعير تلقائي لأن معدل الأجر الإضافي سياسة مؤسسية غير محددة. |
| الصورة الشخصية للموظف | جزئي | يوجد عمود «رابط الصورة» (نص). لا تُضمَّن الصور داخل الخلايا تلقائيًا. |
| إعداد أرقام الصفحات في لوحة التحكم | جزئي | مضبوط على التقارير؛ لوحة التحكم تُطبع لكن دون ترويسة مخصّصة. |
| زر تبديل الشهر في تقرير الرواتب | جزئي | التبديل عبر ورقة الإعدادات (لا ماكرو). |
| تحديث فوري عند التعديل | جزئي | يتطلب تفعيل «الحساب التلقائي» في Excel؛ القيم محسوبة لكن إعادة الحساب قد تحتاج `F9` في بعض الحالات. |

## ❌ ميزات لم تُنفَّذ (خارج نطاق XLSX بدون ماكرو)

| الميزة | السبب |
|---|---|
| نظام صلاحيات متعدد المستويات | يتطلب قاعدة بيانات وخادمًا مصادقة؛ حماية الورقة ليست أمانًا حقيقيًا. |
| سجل تدقيق رسمي (Audit Trail) | يتطلب تخزينًا برمجيًا للأحداث؛ غير ممكن بمعادلات فقط. |
| ربط مباشر بقاعدة بيانات أو API | خارج نطاق ملف Excel. |
| إشعارات بريدية/رسائل | تحتاج تكاملًا خارجيًا. |
| قواعد قانونية (ضرائب/تأمينات/نهاية الخدمة) | لا يمكن افتراضها دون تحديد الدولة واللوائح؛ تُدخل يدويًا. |
| توقيع إلكتروني / اعتماد رقمي | خارج نطاق الملف. |
| رفع صور الموظفين وعرضها في التقارير | يتطلب عناصر تحكم تحتاج ماكرو. |
| تحديث لحظي متعدد المستخدمين | ملف Excel مشترك ليس قاعدة بيانات متزامنة. |

## 🔁 تحسينات مقترحة للمرحلة التالية
1. التحويل إلى قاعدة بيانات (SQL/SharePoint) مع نظام مستخدمين وصلاحيات.
2. تطبيق ويب بواجهة عربية مربوط بنفس النموذج.
3. إضافة تسعير ساعات الإضافي عند تحديد معدل الأجر.
4. تكامل مع أجهزة البصمة لجلب الحضور آليًا.
